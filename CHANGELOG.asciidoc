2025/03/18: Native support for Elixir was added. Erlang.mk
            will now properly handle most Elixir dependencies,
            as well as compile Elixir code in Erlang.mk projects,
            from both src/ and lib/ directories. This allows
            mixing Erlang and Elixir in the same project.
            Please refer to the user guide for more information.
            Native Elixir support is considered experimental.

2026/06/24: The `dep_built` file no longer gets written
            to the `ebin/` folder. It now gets written
            to `$(ERLANG_MK_TMP)/dep_built/`. This may
            break workflows that clean dependencies, they
            will now also need to remove this file manually
            (this does not apply to symlinked deps).

2026/09/22: `make RELOAD=1` was documented for automatic
            code reloading with releases. `make shell RELOAD=1`
            was added for automatic code reloading with
            `make shell`.

2026/09/30: `hex-user-create` and `hex-key-add` were removed.
            Hex no longer accepts the HTTP Basic authentication
            those targets used to create an account and an API key.
            Create the key on Hex. Support is now documented
            in the user guide.

2026/10/01: New `make tree` command prints a human-readable
            dependency tree.

2026/10/02: Erlang.mk now supports only the current Erlang/OTP
            release and the two releases before it. For example,
            when Erlang/OTP 29 is the latest release, the supported
            releases are Erlang/OTP 29, 28, and 27.

2026/10/02: The `hg` and `svn` fetch methods were removed.
            Use Git or Hex or define a custom fetch method.
